# Selection sort | Сортировка выбором

Это простой алгоритм, который на каждом шаге находит минимальный элемент в еще не отсортированной части массива и переносит его в начало.


## Как работает алгоритм:

1. Просматриваем массив, ищем минимальное значение.
2. Меняем найденный минимум местами с первым элементом.
3. Теперь первый элемент считается отсортированным.
4. Повторяем процесс для оставшейся части массива (со второго элемента, затем с третьего и так далее).

### Сложность алгоритма (Big O)

- Сложность по времени: `O(n^2)` во всех случаях (и в лучшем, и в худшем).
- Сложность по памяти: `O(1)` — дополнительная память почти не требуется.
- Устойчивость: Обычно неустойчива (может менять порядок равных элементов).


### Процесс сортировки для массива `[45, 12, 8, 33, 1, 19, 7, 22]`: 

```log
0. [45, 12, 8, 33, 1, 19, 7, 22] - Исходный массив
1. [1, 12, 8, 33, 45, 19, 7, 22] — (нашли 1, поменяли с 45)
2. [1, 7, 8, 33, 45, 19, 12, 22] — (нашли 7, поменяли с 12)
3. [1, 7, 8, 33, 45, 19, 12, 22] — (8 уже на месте)
4. [1, 7, 8, 12, 45, 19, 33, 22] — (нашли 12, поменяли с 33)
5. [1, 7, 8, 12, 19, 45, 33, 22] — (нашли 19, поменяли с 45)
6. [1, 7, 8, 12, 19, 22, 33, 45] — (нашли 22, поменяли с 45)
7. [1, 7, 8, 12, 19, 22, 33, 45] — (33 уже на месте)
```

Итог: `[1, 7, 8, 12, 19, 22, 33, 45]`


#### Пример реализации:
```py
def selection_sort(nums):
    N = len(nums)
    
    for i in range(N - 1):  # Требуется N-1 обменов
        min_idx = i
    
        # Ищем настоящий минимум в остатке массива
        for j in range(i + 1, N):
            if nums[j] < nums[min_idx]:
                min_idx = j
    
        # Меняем местами найденный минимум и текущий элемент
        nums[i], nums[min_idx] = nums[min_idx], nums[i]
    
    return nums
```
