# Insertion sort | сортировка вставками

Берем по очереди каждый элемент и «вставляем» его на правильное место в уже отсортированную левую часть. 

Меняем местами элементы попарно до тех пор, пока исходный не встанет на свое место.


## Как работает алгоритм:

1. Считаем первый элемент уже «отсортированным» массивом.
2. Берем следующий элемент (назовем его «ключ»).
3. Сравниваем «ключ» с элементами слева от него (в отсортированной части).
4. Если элемент слева больше «ключа», сдвигаем этот элемент вправо.
5. Повторяем сдвиг, пока не найдем место, где элемент слева меньше или равен «ключа», либо пока не дойдем до начала.
6. Вставляем «ключ» на пустое место


### Сложность алгоритма (Big O)

Временная сложность:

- Лучший случай: `O(n)` - Если массив уже отсортирован, алгоритм просто проходит по нему один раз. На каждом шаге он делает всего одно сравнение и понимает, что элемент уже на месте.
- Средний случай: `O(n^2)` - В среднем для каждого элемента приходится сдвигать половину уже отсортированной части.
- Худший случай: `O(n^2)` - Если массив отсортирован в обратном порядке, каждый новый элемент придется тащить в самое начало, сдвигая все остальные.
  
Сложность по памяти:

- Затраты памяти: `O(1)` - Алгоритм сортирует массив «на месте». Нам не нужны дополнительные списки, только одна переменная для хранения «ключа» во время перестановки.


> Примечание: Чуть эффективнее, чем "Сортировка Выбором"


### Процесс сортировки для массива `[45, 12, 8, 33, 19, 1, 22, 7]`: 

```log
0. [45, 12, 8, 33, 19, 1, 22, 7] - Исходный массив
1. [12, 45, 8, 33, 19, 1, 22, 7] — (12 вставили перед 45)
2. [8, 12, 45, 33, 19, 1, 22, 7] — (8 вставили в самое начало)
3. [8, 12, 33, 45, 19, 1, 22, 7] — (33 вставили между 12 и 45)
4. [8, 12, 19, 33, 45, 1, 22, 7] — (19 вставили между 12 и 33)
5. [1, 8, 12, 19, 33, 45, 22, 7] — (1 вставили в самое начало)
6. [1, 8, 12, 19, 22, 33, 45, 7] — (22 вставили перед 33)
7. [1, 7, 8, 12, 19, 22, 33, 45] — (7 вставили после 1)
```

#### Пример реализации 1:

```py
def insertion_sort1(nums):
    # Начинаем со второго элемента (индекс 1)
    for i in range(1, len(nums)):
        key = nums[i]  # Текущий элемент, который будем вставлять
        j = i - 1
        
        # Сдвигаем элементы левой части, если они больше "ключа"
        while j >= 0 and nums[j] > key:
            nums[j + 1] = nums[j]
            j -= 1
        
        # Вставляем "ключ" на его законное место
        nums[j + 1] = key
        
    return nums
```


#### Пример реализации 2:

```py
def insertion_sort(nums):
    for i in range(1, len(nums)):
        for j in range(i, 0, -1):
            if nums[j - 1] <= nums[j]:
                break
            nums[j], nums[j - 1] = nums[j - ], nums[j]
    return nums


# Сортировка вставками с компановкой

def _less_than(one, two):
    return one <= two

def insertion_sort_cmp(nums, less=_less_than):
```
