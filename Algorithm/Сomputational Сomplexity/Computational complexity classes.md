
# Computational complexity classes. Классы вычислительной сложности 

Классы вычислительной сложности — это множества задач, сгруппированных по объему ресурсов (времени и памяти), необходимых для их решения. Они позволяют оценивать эффективность алгоритмов на основе размера входных данных.

## Ключевые классы сложности

- Класс P (полиномиальное время): Задачи, которые можно решить на стандартном компьютере за время, ограниченное полиномом `(O(n^k)`, где `n` — объем данных, `k` — константа). Они считаются «легкими» и эффективно решаемыми.
- Класс NP (недетерминированное полиномиальное время): Задачи, для ответа на которые нужно время, экспоненциально растущее с ростом данных. Однако правильность предложенного ответа можно проверить за полиномиальное время. Самый известный вопрос в информатике — равны ли классы P и NP.
- Класс NP-полные: Самые сложные задачи из класса NP. Если хотя бы одну из них удастся решить за полиномиальное время, то можно будет быстро решать все задачи из класса NP.Класс NP-трудные: Задачи, которые как минимум так же сложны, как задачи из NP, но им не обязательно принадлежать к самому классу NP (им можно дать только приблизительный или частичный ответ).
- Класс EXPTIME (экспоненциальное время): Задачи, решение которых требует времени порядка `2^p(n)`, где `p(n)` — полином. Они решаются только для очень малых объемов данных.


## Оценка сложности алгоритмов (Big O нотация)

Базовый уровень сложности алгоритмов часто определяют с помощью нотации __Big O__, которая показывает предел роста времени работы при увеличении входного массива `n`.


## Оценка по памяти

Аналогично времени, алгоритмы классифицируются по объему необходимой оперативной памяти `SpaceComplexity`. Он также измеряется через нотацию __Big O__ (например, алгоритм может требовать память `O(1)` — то есть выделять фиксированный объем, или `O(n)` — создавать копию массива).
