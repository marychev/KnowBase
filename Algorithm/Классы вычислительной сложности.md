# Основные классы вычислительной сложности

Экспоненциальные
- O(N!) - факториальная 
- O(2N) - экспоненциальная

Полиномиальная 
- O(N^3) - кубическая 
- O(N^2) - квадратичная
- O(N log(N)) - N-логарифмическая (для многих задач лучший случай) 
- O(N) - линейная

Долинейная (эффективная)
- O(log(N)) - логарифмическая 
- O(1) - константная (время выполнения постоянно, не зависит от размера входных данных)

Если сложность алгоритма одной части оценивается как `O(N log(N))`, а другой `O(N^2)`, то сложность оценивается как `O(N^2)`!
