# Хэш / hash

Хэш (ассоциативный массив) - это наложить дополнительное требование на свойство ключа.

```
months = 31,    28,     31,     30, ..., 31 
keys = "Янв", "Фев", "Март", "Апр", .., "Дек"
```

- `key in keys` - худший случай, т.к. будут просмотрены все строки в `keys`
- время поиска значения по ключу в этой структуре прямо пропорционально кол-ву ключей
```py
idx = keys.index(month:str)
days = months[idx]
```

- `keys.index()` - просматривает до N элементов, поэтому сложность: `O(N)`.
- Поиск по ключу `months[idx]` - сложность: `O(1)` (механизм `dict`).


### Хэш функции и хэш суммы

- `base32(str) % 35` - пример хэш-функции
- `hash()` - вычисление хэша в python



## Стратегия открытой адресации: (правило свободной ячейки)

Например, эффективно реализовать абстракцию __Очередь (FIFO)__ с помощью `list()` нельзя. Для этого используют `collection.queue`, в которой операции с обоих концов быстры (за счет некоторых накладных расходов).


## Хэширование с раздельными цепочками
```
| x | 15 | x | x | x |  5 |  -> 5  % 7 = 5
                     | 26 |  -> 26 % 7 = 5
                     | 19 |  -> 19 % 7 = 5
```

## Расширяемы таблицы

Основываются на пороговой загруженности.
```
threshold = min(M * load_factor, M-1)
```
Пример: load_factor = 0.75, М = 10

Требование к хэш-функции - равномерное распределение хэшей на всем множестве значений.

Переполнений хэш-таблицы в упрощенной форме - механизм `list()`, т.к. его размер можно менять. `list()` по сути, массив с геометрическим масштабированием при добавлении, т.е. динамический массив.

Когда случается порог(threshold), то выделяется фрагмент памяти (вдвое большей) и туда будет помещена текущая копия содержимого ячеек, добавлено новое значение (ссылка на объект), а старый будет освобожден.
