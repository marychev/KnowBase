# Сложность по времени и сложность по памяти
 
```
С(N)  - формула оценки сложности по времени
T(N) = t * C(N) 
```
- T - время затраченное на работу алгоритма
- t - фикисрованное время выполнения 1й машинной инструкции


## Анализ алгоритмов

Оценка сложности с помощью имперической модели (регрессионные модели можно построить с помощью SciPy).

- `TL(N) = a * N + b` - линейное приближение
- `TQ(N) = a * N^2 + b * N` - квадратичное приближение
- `TN(N) = a * log2(N)` - логарифмическое приближение


Пример: `4N^2 + 3N - 5` - "порядка `N^2`" (или квадратичная), т.к. быстрее всего в этом многочлене растет 1е слогаемое, в котором степень `N = 2`.


Для оценки быстродействия алгоритма на наборе данных, размером `N`, обычно начинают считать количество выполненных им действий:
```py
for i in range(100):
    for j in range(N):
        ct += 1
```
Сложность `O(N)`. 

1. `ct += 1` выполняется `100 * N` раз.
2. `range(N)` - константная сложность `O(1)`
