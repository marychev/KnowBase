# MAX

```py
N = [3, 1, 4, 1, 5, 9, 2, 6]
max(N)
```

1. Срваниваем попарно и поллучаем
```
[3, 1, 4, 1, 5, 9, 2, 6]
|..1..|..2..|..3..|..4..| ==> 4 сравнения

[3, 4, 9, 6]
|..5..|..6..| ==> 2 сравнения

[4, 9]
|..7..| ==> 1 сравнение

[9]
```

Получаем: 7 сравнений.  `len(N) = 8`. Т.е `7 - сравнений - 8 N` = `N - 1` требуется на поиск.
```
8 = 2^3 = log2(8) = 3
N = 8
```
