# «Умный веб-краулер с ограничением глубины и семафором» (Bounded Parallelism)

Классическая задача на собеседованиях в Go, где проверяется умение ограничивать количество одновременно работающих горутин и защищать общую память.
• Условие: Есть мок-функция Fetch(url string) ([]string, error), которая возвращает список ссылок на странице.
• Задача:
	1. Начиная с startURL, обойти граф ссылок до глубины maxDepth (например, 3).
	2. Ни одну ссылку нельзя скачать дважды (нужна потокобезопасная мапа посещенных URL).
	3. Одновременно может выполняться не более K запросов (например, 4) — реализовать это через буферизированный канал-семафор (sem := make(chan struct{}, 4)).
	4. Программа должна корректно завершиться ровно в тот момент, когда закончатся все активные загрузки и не останется новых ссылок.
• Что тренирует: Каналы как семафоры, комбинацию sync.Mutex + sync.WaitGroup + каналы, рекурсивный запуск горутин без дедлоков.
