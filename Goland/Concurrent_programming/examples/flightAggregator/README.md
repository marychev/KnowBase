# «Агрегатор авиабилетов» (Паттерн Scatter-Gather + First Response / Hedged Requests)

Эта задача идеально показывает, как запрашивать данные из нескольких медленных источников одновременно и не ждать тех, кто «тупит».
• Условие: У тебя есть 5 внешних API авиакомпаний (эмулируются функциями с разным time.Sleep от 100 мс до 3 секунд и случайными ошибками).
• Задача:
	1. Отправить запрос всем 5 провайдерам одновременно.
	2. Установить общий жесткий дедлайн на поиск (например, 800 мс).
	3. Собрать все ответы, которые успели прийти за эти 800 мс, отбросив ошибки и тех, кто не успел.
	4. Усложнение (Хеджирование / Гонка): Сделать второй режим — вернуть самый первый успешный ответ, а запросы к остальным 4 провайдерам мгновенно отменить через context.WithCancel(), чтобы не тратить ресурсы.
• Что тренирует: Динамическое управление контекстами, паттерн Fan-In без блокировки на медленных горутинах, буферизированные каналы для предотвращения утечек при раннем выходе.
