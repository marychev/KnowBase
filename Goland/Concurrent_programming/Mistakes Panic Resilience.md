# Ошибки, паники и устойчивость | Mistakes, Panic, and Resilience

Ключевой момент: неперехваченная паника в любой горутине завершает всю программу. Не важно, случилась она в main или в самой незаметной фоновой горутине — если её никто не поймал через recover, процесс печатает стек-трейс и умирает с кодом выхода 2.

В чем проблема?

- Одна горутина роняет весь сервис: паника в самом второстепенном фоновом воркере убивает процесс целиком — вместе со всеми запросами, которые он в этот момент обрабатывал.
- Поймать снаружи нельзя: recover работает только внутри той горутины, где случилась паника. Обернуть go doWork() в defer/recover из main не получится — если внутри воркера нет своей «страховки», программу уже не спасти.
- Незавершенная работа: всё, что делали остальные горутины, обрывается на полуслове — данные могут остаться недописанными.

## Решение: defer + recover внутри воркеров

> Важно: recover() работает, только если его вызвать из отложенной (defer) функции внутри той же горутины, где произошла паника.

код: Устойчивый воркер с recover
Этот пример показывает, как использовать defer и recover для обработки паник внутри горутины. Это позволяет предотвратить "падение" горутины и получить полезную информацию для отладки.

```go
package main

import (
    "fmt"
    "time"
)

// safeWorker теперь устойчив к паникам
func safeWorker(id int) {
    // Устанавливаем "страховку" в самом начале функции
    defer func() {
        if r := recover(); r != nil {
            // Если произошла паника, мы ее ловим, логируем и горутина завершается gracefully
            fmt.Printf("Воркер #%d упал, но был пойман! Причина: %v\n", id, r)
        }
    }()

    fmt.Printf("Воркер #%d начинает работу...\n", id)
    if id == 2 {
        panic(fmt.Sprintf("воркер #%d не любит двойки", id))
    }
    fmt.Printf("Воркер #%d успешно завершил работу.\n", id)
}

func main() {
    for i := 1; i <= 3; i++ {
        go safeWorker(i)
    }

    // Даем воркерам время на работу
    time.Sleep(1 * time.Second)
    fmt.Println("Main завершил работу.")
}

// Воркер #1 начинает работу...
// Воркер #1 успешно завершил работу.
// Воркер #3 начинает работу...
// Воркер #3 успешно завершил работу.
// Воркер #2 начинает работу...
// Воркер #2 упал, но был пойман! Причина: воркер #2 не любит двойки
// Main завершил работу.
```

## Идея «Supervisor»‑горутин (без построения целого Erlang)

А что если мы хотим не просто поймать панику, а перезапустить упавшего воркера? Здесь на помощь приходит паттерн "Supervisor" (Надзиратель).

Как это работает:

1. Supervisor запускает Worker.
2. Worker внутри себя имеет defer/recover.
3. Когда Worker ловит панику, он не просто логирует ее, а отправляет информацию об ошибке в специальный канал, за которым следит Supervisor.
4. Supervisor получает сообщение об ошибке, логирует ее и... запускает нового воркера на замену.

Supervisor, перезапускающий воркеров
Этот пример демонстрирует паттерн "Supervisor" — специальную горутину, которая следит за воркерами и перезапускает их при падении. Это позволяет создавать самовосстанавливающиеся системы.

```go
package main

import (
    "fmt"
    "time"
)

// Воркер сообщает надзирателю об итоге: ошибка (была паника) или nil (успех)
func worker(id int, doneCh chan<- error) {
    defer func() {
        if r := recover(); r != nil {
            // Сообщаем надзирателю о панике
            doneCh <- fmt.Errorf("воркер #%d упал: %v", id, r)
            return // важно: после паники второй итог не отправляем
        }
        doneCh <- nil
    }()

    fmt.Printf("Воркер #%d запущен.\n", id)
    // Имитируем работу, в которой может произойти паника
    time.Sleep(500 * time.Millisecond)
    if id%2 == 0 { // Каждый второй воркер падает
        panic("случайная паника")
    }
    fmt.Printf("Воркер #%d завершил работу успешно.\n", id)
}

// Надзиратель следит за воркерами
func supervisor() {
    doneCh := make(chan error)
    workerID := 1

    for {
        fmt.Printf("Надзиратель запускает воркера #%d...\n", workerID)
        go worker(workerID, doneCh)

        // Ждем итог от воркера (о панике или об успешном завершении)
        err := <-doneCh
        if err != nil {
            fmt.Printf("Надзиратель получил сообщение: %v. Перезапускаю...\n", err)
        }
        workerID++
    }
}

func main() {
    go supervisor()

    // Даем надзирателю поработать несколько секунд
    time.Sleep(5 * time.Second)
    fmt.Println("Main завершает работу.")
}
```
