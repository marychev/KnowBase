# Maps

Мапа (map) — это встроенная структура данных в Go, которая хранит неупорядоченную коллекцию пар "ключ-значение". Каждый ключ уникален, и по нему можно быстро получить связанное значение.

Если вы заранее знаете примерное количество элементов, используйте make с указанием ёмкости:

```go
// Создаём мапу с помощью make
users := make(map[int]string)

// Можно указать начальную ёмкость для оптимизации
usersWithCapacity := make(map[int]string, 100) // ← Резервируем место для ~100 элементов
```

Можно объявить мапу без инициализации, но тогда её значением будет nil. Важно понимать разницу: чтение из nil-мапы безопасно, но попытка записи вызовет панику. Поэтому перед использованием такую мапу нужно инициализировать:

```go
var m map[string]int  // m == nil (нулевая мапа)

// ❌ Попытка добавить элемент в nil-мапу вызовет панику!
// m["key"] = 123

// ✅ Сначала нужно инициализировать
m = make(map[string]int)
m["key"] = 123  // Теперь всё работает

// ✅ Правильно: проверяем существование
discount, exists := discounts["platinum"]
if exists {
    fmt.Printf("Скидка platinum: %d%%\n", discount)
} else {
    fmt.Println("Уровень platinum не найден")
}
```


### Сортированная итерация

Если нужен предсказуемый порядок, сначала соберите ключи в слайс и отсортируйте их:

```go
package main

import (
    "fmt"
    "sort"
)

func main() {
    ages := map[string]int{
        "Charlie": 35,
        "Alice":   25,
        "Bob":     30,
    }

    // Собираем ключи в слайс
    names := make([]string, 0, len(ages))
    for name := range ages {
        names = append(names, name)
    }

    // Сортируем ключи
    sort.Strings(names)

    // Итерируем в отсортированном порядке
    fmt.Println("Возрасты в алфавитном порядке:")
    for _, name := range names {
        fmt.Printf("%s: %d\n", name, ages[name])
    }
}
```

## Пакет maps

Функция maps.Clone создаёт новую мапу и копирует в неё все пары ключ-значение. Важно понимать, что это поверхностная копия: копируется сама мапа и её элементы, но если значения являются ссылочными типами (слайсы, указатели, другие мапы), то они будут общими между оригиналом и копией.

Функция maps.Copy позволяет скопировать все элементы из одной мапы в другую.

В Go нельзя напрямую сравнивать мапы с помощью оператора ==. Функция maps.Equal решает эту проблему, выполняя поэлементное сравнение.

Функция maps.DeleteFunc позволяет удалить все элементы, которые удовлетворяют заданному условию. Это удобнее, чем перебирать мапу и вызывать delete для каждого элемента.

Функции maps.Keys и maps.Values возвращают итераторы по ключам и значениям соответственно. Для преобразования итератора в слайс используется slices.Collect.
