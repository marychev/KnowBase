# структура

Структура (struct) — это пользовательский тип данных, который группирует несколько связанных значений (полей) под одним именем. Каждое поле имеет своё имя и тип.

> Важно!
> Имена полей, начинающиеся с заглавной буквы, экспортируются (видны за пределами пакета). Имена с строчной буквы — приватные для пакета.

Размер структуры в памяти зависит не только от размеров полей, но и от их порядка. Компилятор добавляет padding (пустые байты) для выравнивания данных:

```go
type Example1 struct {
    A int8   // 1 байт
    B int64  // 8 байт → требует padding перед собой
    C int8   // 1 байт
}
// Размер: 24 байта (из-за padding)

type Example2 struct {
    B int64  // 8 байт
    A int8   // 1 байт
    C int8   // 1 байт
}
// Размер: 16 байт (меньше padding)
```

Группируйте поля одного размера для экономии памяти. Это особенно важно для структур, которые создаются в больших количествах.

Функция new выделяет память для структуры и возвращает указатель на неё:

```go
user := new(User)
// user — это *User (указатель)
// Все поля инициализированы нулевыми значениями

user.Name = "Eve"  // Go автоматически разыменовывает указатель
user.Age = 28
```

В Go структуры копируются по значению при присваивании: Изменения в одной структуре не влияют на другую.

При передаче структуры в функцию создаётся её копия. Чтобы изменить оригинальную структуру, нужно передавать указатель. При копировании структуры, содержащей слайсы, мапы или указатели, копируются только ссылки, а не данные.

Для глубокого сравнения можно использовать функцию DeepEqual из стандартного пакета reflect. Этот пакет предоставляет возможности рефлексии — анализа типов и значений во время выполнения. DeepEqual рекурсивно сравнивает все поля на любую глубину вложенности — включая слайсы в структурах, структуры в слайсах, мапы с вложенными данными и так далее:

```go
import "reflect"

func main() {
    u1 := User{Name: "Alice", Roles: []string{"admin"}}
    u2 := User{Name: "Alice", Roles: []string{"admin"}}

    // DeepEqual сравнивает содержимое слайсов, а не только ссылки
    fmt.Println(reflect.DeepEqual(u1, u2)) // true
}
```

## Теги полей

Поля структуры могут иметь теги — строковые метаданные, которые используются пакетами для настройки поведения:

```go
type User struct {
    ID        int    `json:"id"`
    Name      string `json:"name"`
    Email     string `json:"email"`
    Password  string `json:"-"`              // Исключить из JSON
    CreatedAt int64  `json:"created_at,omitempty"` // Не включать, если ноль
}
```

Валидация:

```go
type User struct {
    Name  string `validate:"required,min=3,max=50"`
    Email string `validate:"required,email"`
    Age   int    `validate:"gte=0,lte=130"`
}
```
