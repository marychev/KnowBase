# Режимы движения данных. Data movement modes.

При каждой отправке данных другому процессу, с которым у вас нет совместно используемой памяти (например, при отправке данных по сети или записи их в файл), необходимо кодировать их в байтовую последовательность.

Наиболее распространенных способов движения данных между процессами:

- через БД («Поток данных через БД»);
- с помощью вызовов сервисов («Поток данных через сервисы:REST и RPC»);
- путем передачи асинхронных сообщений («Поток данных передачи сообщений» текущего раздела).
