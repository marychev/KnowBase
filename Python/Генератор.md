# Генератор

Это вычисляемая последовательность, в которой не нужно задействовать отдельную память со списком этих данных.

Оператор `yield` - означает, что это генератор функция. Пример:
```py
gen = avoid_digit(15, 3)   # yield  вместо return

for i in gen:
    print(i)  # тут будет результат 

for i in gen:
    print(i)  # тут уже ничего нет!
```

Генератор можно считать одноразовым.

Не путать с __итератором__! Если в _python-классе_ задать метод `__iter__()`, то сконфигурированный из этого класс станет __итерируемым__, т.е его можно будет использовать в конструкции `for i in obj`.

Пример: метод-итератор, реализованный как генератор-функция:
```py
class Hastable:
    ...
    def __iter__(self):
        for i in self.table:
            if entry:
                yield i.key, i.value
```
