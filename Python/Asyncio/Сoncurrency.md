# Конкурентность. Сoncurrency.

Позволяет выполнять более одной задачи, постоянно переключаясь между ними, как бы чередуя процессами.

Главная задача: Эффективное использование ресурсов системы. Пока одна задача ожидает ответа (например, загружает данные из сети), процессор не простаивает, а переключается на выполнение другой задачи.
