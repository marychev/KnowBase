# Асинхронное программирование. Asynchronous programming.

Асинхронное программирование — это метод, при котором программа не блокирует основной поток во время выполнения долгих операций (например, сетевых запросов или чтения файлов). Вместо ожидания завершения задачи, программа продолжает работу, а результат получает позже. Это когда приложение, а не процессор управляет потоками и переключением контекста. Только 1му потоку разрешено работать в опред.момент времени. Переключение контекста отнимает время и ресурсы процессора.

Решает проблемы:

- процессорное переключение контекста (использует event loop), переключение контестк программно `await`
- состояние гонки 
- взаимных блокировок (нет состояния гонки нет и блокировок)
- исчерпания ресурсов, т.к. корутины запускаются в 1 потоке и не требуют дополнительной памяти

Но нехватку ресурсов можно достичь путем запуска слишком многих процессов.

__Asyncio__ -  исполняет программы асинхронно, пользуясь моделью конкурентности, получившей название _однопоточный цикл событий_.
