# Код ревью / Review code

## Сводка команд

### `/simplify` 

- Что делает: git diff → 3 параллельных агента (reuse / quality / efficiency) → агрегирует находки → сам правит код	
- Что даёт: список фиксов + применённые правки	
- Когда использовать: после любых правок до коммита — самая полезная


### `/security-review`

- Что делает: review pending changes на security-проблемы (env-инъекции, exposed ports, secrets, OWASP)	
- Что даёт: список уязвимостей + severity	
- Когда использовать: перед PR, особенно если трогаешь auth/network/env/Dockerfile


### `/review`	
- Что делает: PR-style ревью: качество, читаемость, корректность, edge cases
- Что даёт: замечания списком, без правок	
- Когда использовать: как second-opinion перед merge

### `/ultrareview`
- Что делает: то же что /review, но в облаке, multi-agent, billed	
- Что даёт: детальный отчёт	
- Когда использовать: для крупных PR, когда нужна глубина и не жалко денег!



## Как запускать в любом проекте

Просто введи в чате с Claude Code:

```sh
/simplify              # ревью diff текущей ветки + автофиксы
/simplify <файлы>      # ограничить scope конкретными файлами
/security-review       # security pending changes
/review                # читаемый PR-стайл ревью
/review <PR_NUMBER>    # ревью PR с GitHub
/ultrareview           # cloud, локальный diff
/ultrareview <PR#>     # cloud, конкретный PR
```


## Что когда выбирать (decision tree)

- `/simplify`: Дописал фичу, перед коммитом
- `/simplify` (он покрывает quality issues): Архитектурная правка
- `/security-review + /review`: Перед git push / открытием PR
- `/ultrareview <PR#>` Большой PR, важный, готов заплатить за глубину	
- `/review` Только diff диагностика без фиксов	


### Рекомендация для будущего workflow

- Минимальный gate перед коммитом: `/simplify`
- Перед PR (опционально): `/security-review`
- И лишь для критичных PR (auth, payments, миграции данных): `/ultrareview`

## Superpower для Claude Code

Плагин для терминального интерфейса Claude Code - это бесплатный open-source фреймворк. Он добавляет агенту «навыки» для дисциплинированной разработки: сначала планирование и проектирование, затем написание тестов и только потом кода. Это надстройка (часто в виде набора инструкций или MCP-серверов), которая превращает Claude в терминале из просто «умного чата» в автономного инженера.

Его ключевые фишки:
- Дисциплинированный рабочий процесс: Он заставляет Claude сначала писать план (дизайн-документ), затем тесты, и только потом код.
- MCP-интеграция (Model Context Protocol): Позволяет Claude напрямую подключаться к вашим базам данных (включая ClickHouse), GitHub, Google Drive или локальным инструментам анализа кода.
- Автономный режим: Вы даете задачу (например, «интегрируй Kafka в FastAPI проект»), и Claude сам создает файлы, запускает тесты и исправляет ошибки, пока не добьется результата.
